## Long Description

**MD for AI** is a lightweight, accessible, and 100% local-first browser extension that converts any article, technical documentation, or web page into clean, structured Markdown ready to feed into your AI prompts (ChatGPT, Claude, Gemini, DeepSeek, Cursor, or local models).

### 🚀 Key Features

- **100% Local and Private:** Zero network requests, zero telemetry, and zero backend servers. All conversion and token estimation happens entirely inside your browser.
- **Smart Article Extractor:** Powered by Mozilla's Readability engine to strip ads, navigation sidebars, and trackers, leaving only high-signal content.
- **3 Flexible Extraction Modes:**
  - *Article:* Extracts main readable body and metadata frontmatter.
  - *Full Page:* Converts the whole page while sanitizing scripts and styles.
  - *Selection:* Converts only the text highlighted on the page.
- **GFM Tables & Code Blocks with Languages:** Preserves table formatting and fenced code blocks with automatic programming language tags (TypeScript, Python, Rust, Go, HTML, etc.).
- **Offline Token Estimator (0 ms):** Instantly displays the estimated token count with limit chips (8k, 32k, 128k, 200k) indicating whether the text fits your target LLM context window.
- **Smart Token Trimming:** Truncates long pages to your chosen token budget at paragraph or line boundaries, ensuring fenced code blocks are never left unclosed.
- **Fast Keyboard Shortcut:** Launch and extract instantly with `Alt+Shift+M` (customizable in `chrome://extensions/shortcuts`).
- **Optional Auto-Copy on Open:** Streamline repetitive workflows by copying clean Markdown straight to your clipboard when the popup opens.
- **Accessible & High-Contrast Design:** Native dark and light mode support, keyboard-first focus management, and bilingual interface (English / Spanish).
