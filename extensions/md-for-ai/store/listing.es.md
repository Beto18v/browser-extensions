Convertir artículos y páginas web a Markdown limpio y compacto optimizado para prompts y ventanas de contexto de modelos de lenguaje (LLMs).

## Descripción Larga

**MD for AI** es una extensión de navegador ligera, accesible y 100% local que transforma cualquier artículo, documentación o página web en Markdown estructurado y listo para alimentar tus prompts de Inteligencia Artificial (ChatGPT, Claude, Gemini, DeepSeek, Cursor o modelos locales).

### 🚀 Características Principales

- **100% Local y Privado:** Cero llamadas de red, cero analíticas y cero servidores backend. Todo el procesamiento ocurre de forma inmediata dentro de tu navegador.
- **Extractor de Artículos Inteligente:** Integra el motor Readability de Mozilla para descartar barras laterales, menús de navegación, anuncios y trackers, extrayendo únicamente el núcleo del contenido.
- **3 Modos de Extracción:**
  - *Artículo:* Extrae el cuerpo principal y metadatos relevantes.
  - *Página Completa:* Convierte la totalidad del documento sanitizando scripts e iframes.
  - *Selección:* Convierte únicamente el fragmento de texto que tengas seleccionado en la página activa.
- **Tablas GFM y Bloques de Código con Lenguaje:** Genera tablas Markdown nativas y bloques de código cercados con detección automática de sintaxis (TypeScript, Python, Rust, Go, CSS, etc.).
- **Estimador de Tokens Local (0 ms):** Conoce de inmediato el tamaño aproximado de tu contexto con chips visuales de límite (8k, 32k, 128k, 200k) que te indican si cabe en tu modelo favorito.
- **Recorte Inteligente por Tokens:** Corta el texto respetando los límites de párrafos o líneas, cerrando automáticamente cualquier bloque de código abierto para no romper la sintaxis.
- **Atajo de Teclado Rápido:** Abre la extensión con `Alt+Shift+M` (o personalízalo en `chrome://extensions/shortcuts`).
- **Copiar al Abrir Opcional:** Automatiza tu flujo de trabajo copiando el Markdown directamente al portapapeles al activar la extensión.
- **Diseño Accesible y Ligero:** Soporte nativo para modo oscuro y claro, navegación completa por teclado y soporte bilingüe (Español / Inglés).
